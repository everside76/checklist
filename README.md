# 고반식당 MOT 점검 웹앱

매장에서 스마트폰으로 **MOT(Moment of Truth) 서비스 체크리스트**를 점검하고, 결과를 **구글 스프레드시트로 자동 전송**하는 모바일 웹앱입니다. 별도 설치 없이 URL 접속만으로 동작합니다.

🥩 **고반식당 전용** (체크리스트 v4 · 8단계 35문항) · 김치옥은 별도 앱으로 운영합니다.

## ✨ 주요 기능
- 주문방식(직접주문/테이블오더)에 따른 점검 항목 자동 분기
- ○ 이행 / △ 미흡(−1) / × 불이행(−2) 3단 평가 + 총점·등급(S/A/B/C) 자동 계산
- 🚫 절대 금지 10계명(위반 1건당 −3)
- 결과를 구글 스프레드시트(`점검요약`·`항목상세`)에 누적 저장
- 오프라인 점검 → 온라인 복귀 시 재전송, CSV 내보내기, 점검 이력
- 진행바·단계 네비게이션 상단 고정, 다크모드, 버전·변경이력 표시

## 📁 구성
| 파일 | 설명 |
|------|------|
| `index.html` | 모바일 웹앱 본체 (단일 파일, 빌드 불필요) |
| `google-apps-script.gs` | 구글 시트 수신 스크립트 (Apps Script) |
| `사용설명서.md` | 설치·연동·사용 상세 가이드 |
| `고반식당_서비스MOT체크리스트_v4_2.xlsx` | 원본 체크리스트 (v4_2) |

## 🚀 사용 방법
1. `index.html`을 웹 호스팅(Netlify/GitHub Pages 등)에 올리거나 브라우저로 열기
2. 기본 구글 시트 연동 URL이 앱에 포함되어 있으므로 별도 설정 없이 점검 시작
3. 다른 구글 시트로 전송해야 할 때만 앱 설정에서 Apps Script 배포 URL 변경

### GitHub Pages로 배포하기
저장소 **Settings → Pages → Branch: `main` / root** 선택 후 저장하면
`https://everside76.github.io/checklist/` 주소로 바로 접속할 수 있습니다.
